# RuneScape: Dragonwilds

## About
This is a template for [RuneScape Dragonwilds](https://dragonwilds.runescape.com).

## Must Knows
#### Owner ID
You must have a valid Owner ID set in order to play on the server. It will not function without one. You can find your Owner ID by opening the RuneScape: Dragonwilds client, going to the settings, and looking at the bottom of the screen.

#### Max Players
Officially, Jagex only supports a max of 6 players on the dedicated server. I have included the option to go above that, but be advised performance may suffer.

#### Memory Requirements
Jagex suggests hosts have 2GB + 1GB per player of RAM. If you have 6 players, you would want 8GB.
