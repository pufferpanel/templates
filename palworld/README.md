# PufferPanel Template for Palworld Dedicated Server

Note: This template only supports Linux at the moment. For any configuration information, please refer to the documentation for the [Palworld Server](https://docs.palworldgame.com/)

## Installation

1. Name the server and select the template
2. Click Install and wait for the downloads and installation to complete

## Configuring the Server

In the `Files` tab of PufferPanel, navigate to `Pal/Saved/Config/LinuxServer` and edit `PalWorldSettings.ini`

A list of up-to-date configuration options can be found on the [Palworld server documentation](https://docs.palworldgame.com/settings-and-operation/configuration)

## Known Caveats

- **Console commands do not work**
  - Not sure why, Palworld servers do not accept console commands
